# Jou Labs EARL trust anchors

Out-of-band trust anchors for independent verification of EARL evidence packages.
Compare these values out-of-band; a package verified without pins is
SELF-CONSISTENT only, and verified against them is authenticated to Jou Labs.

- `EY-TRUST-ANCHORS.md` — EARL evaluation console (containment runtime + fairness audit).
- `TOB-TRUST-ANCHORS.md` — EARL Trail-of-Bits evaluation packet v3 (signed zip, root manifest, publisher key, source commits).
